# 네온 라이더 — 몸으로 조종하는 오토바이 게임 기획서

## 레퍼런스 분석 (참고 영상, 10초)
| 장면 | 관찰한 것 | 게임에 반영 |
| --- | --- | --- |
| 노트북 앞에서 두 주먹을 쥐고 핸들 잡는 자세 | 컨트롤러 없이 **웹캠 + 몸동작**으로 조종 | MediaPipe Pose로 손목·어깨·코 추적 |
| 화면 왼쪽 아래 작은 웹캠 창, 몸 위에 하늘색 선 | 인식된 **스켈레톤 오버레이** | PiP 웹캠 + 관절/뼈대 그리기 |
| 1인칭 시점, 분홍 차체 + 핸들 위 속도계 화면 | **콕핏 1인칭 뷰** | 핸들바, 분홍 페어링, 캔버스로 그린 속도계 |
| 남색·보라 밤 고속도로, 분홍 네온 가장자리, 하늘의 빛줄기, 고층 빌딩 | **신스웨이브/사이버 네온** 분위기 | 안개 + 블룸, 네온 가드레일, 창문 불빛 빌딩, 빛줄기 |
| 파랑·흰색 박스형 차들이 같은 방향으로 달림 | **차 사이로 빠져나가는** 게임 | 4차선 교통, 아슬아슬 통과 보너스 |
| 사람이 몸을 크게 기울이자 라이더가 날아가며 바이크와 분리 | **충돌 → 3인칭 슬로모션 랙돌** | 라이더/바이크 각각 회전하며 튕겨나감 |
| 화면 중앙 **WASTED** | GTA식 사망 연출 | 흑백 전환 + 슬로모션 + WASTED 글자 |

## 핵심 재미
1. **몸이 곧 컨트롤러** — 핸들을 잡은 것처럼 두 주먹을 들고, 기울이면 바이크가 기운다.
2. **속도감** — 블룸 네온, 빛줄기, 속도에 따라 넓어지는 화각, 엔진음.
3. **아슬아슬함** — 차를 스칠 듯 지나가면 콤보 보너스, 실수하면 화려하게 WASTED.

## 조작
### 몸 (웹캠, 기본)
| 동작 | 인식 방법 | 게임 |
| --- | --- | --- |
| 두 주먹을 가슴 앞에 (핸들 잡기) | 두 손목이 보이고 어깨~엉덩이 높이 사이 | 가속 |
| 핸들 돌리듯 한쪽 손을 내림 / 몸 기울이기 | 두 손목을 잇는 선의 기울기(65%) + 어깨선 기울기(35%) | 좌우 기울기(조향) |
| 몸을 화면 쪽으로 숙이기 (턱) | 어깨 폭이 기준 대비 15% 이상 커짐 | 부스터 (게이지 소모) |
| 손을 내림 (핸들 놓기) | 손목이 엉덩이 아래이거나 안 보임 | 감속 |
| 두 손을 머리 위로 1초 | 두 손목이 코보다 위 | 시작 / 다시 시작 |

- 처음 핸들을 잡으면 1.5초 동안 어깨 폭을 재서 **보정**(사람마다 카메라 거리가 다름).
- 조향은 데드존 4° + 지수 이동 평균으로 떨림 제거.
- 웹캠 영상은 거울처럼 좌우 반전해서 보여 주고, 계산도 사용자 기준(오른손=오른쪽)으로 한다.

### 키보드 / 터치 (웹캠이 없을 때)
- ←/→ (A/D) 조향, ↓ (S) 브레이크, Space/Shift 부스터, Enter/R 재시작, M 소리 끄기
- 폰: 화면 왼쪽/오른쪽 절반을 누르고 있으면 조향, 두 손가락 = 부스터

## 게임 규칙
- 끝없는 4차선 고속도로(차선 폭 3.6m). 모든 차는 같은 방향으로 54~110km/h로 달리고, 가끔 차선을 바꾼다.
- 바이크 최고 속도 200km/h, 부스터 250km/h. 속도가 빠를수록 기울기 반응도 크다.
- 점수 = 달린 거리(m) × 속도 배율 + 아슬아슬 통과(옆 1.3m 이내, 100km/h 이상) 100점 × 콤보.
  콤보는 3초 안에 다시 아슬아슬하게 지나가야 이어진다.
- 부스터 게이지: 아슬아슬 통과 시 충전, 사용 시 초당 25% 소모.
- 가드레일에 부딪히면 불꽃 + 속도 30% 감소 (죽지는 않음).
- **차와 부딪히면 WASTED**: 라이더와 바이크가 따로 날아가고(충돌 속도 기반 물리), 카메라가 3인칭으로 빠지며
  0.3배 슬로모션 → 흑백 → "WASTED". 점수와 최고 기록(브라우저 저장)을 보여 준다.
- 달린 거리에 따라 교통량이 늘어난다 (차 간격 70m → 22m).

## 화면 구성
- **타이틀**: 로고 NEON RIDER, [웹캠으로 플레이] [키보드로 플레이], 조작법 그림.
- **주행**: 1인칭 콕핏(속도계는 실시간 캔버스 텍스처), 왼쪽 위 점수/거리/콤보, 오른쪽 위 최고 기록,
  왼쪽 아래 웹캠 PiP + 스켈레톤 + 인식 상태("핸들을 잡으세요"), 아래쪽 부스터 게이지.
- **WASTED**: 흑백 + 비네트, 중앙 WASTED, 점수/최고 기록, "두 손을 머리 위로 / R 키로 다시 시작".

## 기술 구조
기존 저장소(Vite + TypeScript + Three.js)에 두 번째 페이지 `ride.html`로 추가한다. 빌드 시 두 페이지 모두 `dist/`에 들어가
GitHub Pages에서 `/memoryz/ride.html`로 바로 열린다.

```
ride.html              진입 페이지 (HUD/오버레이 DOM)
src/ride/
  core/                순수 로직 (DOM/Three 의존 없음, 고정 60Hz, 시드 난수 → 단위 테스트)
    constants.ts         도로·속도·점수 수치
    sim.ts               바이크 물리, 교통 생성/차선 변경, 충돌, 아슬아슬, 점수, 충돌 후 랙돌 물리
    controls.ts          포즈 랜드마크 → { 조향, 가속, 브레이크, 부스터, 만세 } 변환 + 보정
  input/
    pose.ts              웹캠 + MediaPipe PoseLandmarker(lite, GPU→CPU 폴백)
    keyboard.ts          키보드/터치 입력
  render/
    scene.ts             렌더러, 블룸/흑백 후처리, 카메라(1인칭 ↔ 3인칭)
    road.ts              도로(차선 텍스처 스크롤), 네온 가드레일, 빌딩, 빛줄기, 하늘
    vehicles.ts          교통 차량 모델 (인스턴스 재사용)
    bike.ts              콕핏(1인칭), 3인칭 바이크 + 라이더 모델
    dashboard.ts         속도계 캔버스 텍스처
  ui/
    hud.ts               점수, 콤보 팝업, 부스터 게이지, 상태 메시지, 화면 전환
    skeleton.ts          웹캠 PiP 위에 스켈레톤 그리기
  audio.ts             WebAudio 합성 엔진음(기어별 rpm), 바람, 아슬아슬 휙, 충돌, WASTED 효과음
  main.ts              상태 머신: 타이틀 → 주행 → WASTED → 재시작
tests/ride/            sim / controls 단위 테스트
```

- 포즈 모델과 wasm은 CDN(jsdelivr, Google Storage)에서 불러온다. 실패하면 키보드 모드로 자동 전환하고 안내한다.
- 렌더링은 플레이어 기준 좌표(모든 물체를 `z - playerZ`에 그림)로 해서 멀리 달려도 부동소수점 떨림이 없다.

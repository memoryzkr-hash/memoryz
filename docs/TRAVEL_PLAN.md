# 🧳 여행 플래너 + 이동 시뮬레이터 기획서

> "어디든 여행 계획을 세워 주고, 그 계획대로 움직이는 걸 지도 위에서 시뮬레이션해서 보여 주고,
> 이동 시간과 비용을 미리 알 수 있게" — 이 요구를 `travel.html` 한 페이지로 만든다.

## 1. 목표

| 하고 싶은 것 | 이렇게 만든다 |
| --- | --- |
| 아무 여행지나 계획 | Claude에게 목적지·기간·인원·예산·스타일·관심사를 주면 **날짜별 방문지(좌표 포함)** 를 받는다 |
| 이동 시뮬레이션 | 지도(Leaflet + OpenStreetMap) 위에서 여행자 아이콘이 일정 시간표대로 움직인다. 재생/일시정지/배속/되감기 |
| 이동·비용 예측 | AI가 아니라 **정해진 공식**(거리·수단·시간대·지역 요금표)으로 계산 → 같은 계획이면 언제나 같은 숫자 |
| 직접 시연 | API 키가 없어도 **샘플 여행 4개**(서울·제주·도쿄·파리)로 바로 재생. 지도를 눌러 장소를 추가하고 수단을 바꾸면 결과가 즉시 다시 계산된다 |

**역할 분담이 핵심**: AI는 "어디를 갈지"(내용)만, 숫자(시간·비용)는 앱의 결정적 엔진이 맡는다.
AI가 지어낸 요금이나 시간이 그대로 화면에 나오지 않게 하고, 테스트로 검증할 수 있게 하기 위함.

- 휴대폰: 지도가 위(화면 45%), 일정·비용이 아래로 스크롤.
- 지도를 클릭하면 "여기에 장소 추가" → 이름·머무는 시간·입장료 입력.
- 구간마다 **수단 비교표**(도보/지하철/버스/택시/기차/비행기의 시간·비용)를 펼쳐 볼 수 있다.
- **🔀 동선 최적화**: 첫 장소(숙소)·마지막 장소는 고정하고 나머지 방문 순서를 바꿔 이동 시간을 줄인다. 줄어든 시간·비용을 토스트로 보여 준다.

## 3. 예측 엔진 (`src/travel/core`)

### 3.1 거리
- 두 좌표의 **대권거리(haversine)** × 수단별 **우회 계수**(도로·선로는 직선보다 길다).

### 3.2 시간 = 고정 대기 + 거리 / 속도
| 수단 | 속도 km/h | 우회 계수 | 고정 시간(분) | 비고 |
| --- | --- | --- | --- | --- |
| 🚶 도보 | 4.5 | 1.25 | 0 | |
| 🚇 지하철 | 33 | 1.3 | 10 | 역까지 걷기 + 대기 |
| 🚌 버스 | 19 | 1.3 | 8 | 출퇴근 시간 ×1.35 |
| 🚕 택시 | 거리에 따라 22→65 | 1.3 | 5 | 출퇴근 시간 ×1.35 |
| 🚗 렌터카 | 거리에 따라 25→80 | 1.3 | 3 | 출퇴근 시간 ×1.35 |
| 🚄 기차 | 160 | 1.15 | 25 | 역 이동 + 탑승 대기 |
| ✈️ 비행기 | 700 | 1.05 | 120 | 공항 수속 |
| ⛴️ 배 | 32 | 1.1 | 30 | |

- 출퇴근 시간(07:30–09:30, 17:30–19:30)에 출발하는 도로 수단은 1.35배 느리다.
- `auto`(자동)는 거리로 고른다: 1.2km 미만 도보, 지하철 있는 도시 15km 미만 지하철(없으면 택시), 300km 미만 기차(섬 등 육로 불가 시 비행기), 그 이상 비행기.

### 3.3 비용 = 지역 요금표 × 인원
지역(KR·JP·FR·US·TH·기타)마다 통화와 요금표를 둔다. 예) 한국: 택시 기본 4,800원(1.6km) + km당 1,040원, 22–04시 20% 할증, 지하철 1,400원(10km 초과 5km마다 +100원).
- 택시·렌터카는 **차 한 대 요금**(4명마다 한 대), 대중교통·기차·비행기는 **1인 요금 × 인원**.
- 장소 비용(입장료·식사)은 1인 기준 × 인원. 숙박은 박당 요금 × (인원/2 올림)실 × 박 수.
- 원화 환산은 고정 기준 환율(화면에 표시)로.

### 3.4 일정표
하루 시작 시각부터: 이동 → 도착 → (문 열기 전이면 대기) → 머무름 → 다음 이동.
경고: 닫힌 뒤 도착 / 23시 넘어 끝남 / 한 번에 30분 넘게 걷기 / 하루 이동 시간 4시간 초과 / 예산 초과.

### 3.5 시뮬레이션
일정표를 "머무름"과 "이동" 구간의 타임라인으로 바꾸고, 시각 `t`에서의 위치·상태·누적 비용·누적 거리를 계산하는 **순수 함수**.
경로는 직선을 살짝 휜 곡선(비행기는 큰 호)으로 그린다 — 실제 도로 경로가 아니라는 점을 화면에 표시.

## 4. AI (`src/travel/ai.ts`)
- 모델 `claude-opus-5-5`, structured outputs(JSON 스키마)로 계획 한 번에 받기. 거절 시 서버 측 폴백.
- 키는 개인 비서와 같은 `localStorage` 키를 함께 쓴다(한 번만 입력).
- 받은 JSON은 `validate.ts`가 검사: 좌표 범위, 머무는 시간 10–600분, 비용 0 이상, 하루 1–12곳, 시각 형식. 하나라도 이상하면 고치거나 버린다.

## 5. 테스트 (`tests/travel`)
- geo: 서울–부산 거리 ≈ 325km, 보간 끝점
- estimate: 짧은 거리 auto=도보, 택시 할증, 인원별 대수, 출퇴근 배수, 지하철 거리 요금
- schedule: 개장 전 도착 대기, 마감 후 도착 경고, 예산 초과
- sim: t=시작/끝/중간 위치, 누적 비용 단조 증가
- optimize: 순서를 바꿔 이동 시간이 늘지 않음, 처음·끝 고정
- validate: 잘못된 좌표·빈 일정 거부
- ai: 가짜 fetch로 요청 모양·실패 처리 확인 (실제 API 호출 없음)

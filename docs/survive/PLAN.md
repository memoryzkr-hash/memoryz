# 시험 생존 — 설계 메모

> 전부 공부하지 마세요. 지금 필요한 것부터 살아남게 해드릴게요.

## 누구를 위한 앱인가

평소 공부를 거의 안 하고, 시험이 닥쳐야 시작하고, 범위가 많으면 압도돼서 아예 시작을 못 하는 학생.
목표는 "완벽한 준비"가 아니라 **"망하지 않기"** — 그리고 무엇보다 **일단 시작하게 만드는 것**.

그래서 학생에게 고르게 하지 않는다. 계획·진도·단원·공부 방식·카드 만들기 전부 앱이 정한다.
학생이 누르는 것은 사실상 **시작**, 그리고 카드마다 **답하기 · 모르겠음 · 헷갈림 · 다음** 넷뿐이다.

## 생존 루트 (`core/plan.ts`)

남은 시간으로 **현실적인 공부 시간 예산**을 정하고, 중요도 순으로 그 예산에 들어가는 개념만 담는다.

| 남은 시간 | 예산 |
| --- | --- |
| 3시간 미만 (벼락) | 남은 시간의 절반, 10~40분 |
| 24시간 미만 (오늘 밤) | 40~50분 |
| 그 이상 | 하루 30분 × 남은 날 (최대 7일) |

- 개념 1개 비용 = 카드 시간 합(떠올리기 35초, 설명 25초, 선택형 40초, 암기카드 15초, 유사문제 40초) × 0.85 + 복습 여유.
- 예산 밖의 개념은 **"이번엔 버리는 것"**으로 보여 준다. 숨기지 않는다.
- 계획은 `(시험, 지금 시각)`의 순수 함수라서 열 때마다 다시 계산된다. 시간이 줄면 루트가 줄고, 개념을 끝내면 남은 예산으로 다음 개념이 들어온다(= 실시간 루트 수정).
- 여러 날 남았으면 "오늘 몫"은 남은 루트 ÷ 남은 날.

## 자동코스 엔진 (`core/engine.ts`)

모르는 개념의 기본 경로(요구사항 그대로):

```
떠올리기 → 20초 설명 → 선택형 → 암기카드 → 유사문제 → 다음 핵심개념
```

- 떠올리기에서 **맞았어요** → 선택형 하나로 확인만 하고 설명은 건너뜀. 확인까지 맞히면 그 개념은 끝.
- 확인 문제를 틀리면 → 설명 + 유사문제를 붙임.
- **모르겠음 / 헷갈림 / 틀림**이 한 번이라도 있으면 그 개념은 끝난 뒤 "헷갈림"으로 표시되고, 카드 4장 뒤에 **복습**으로 다시 나온다. 한 번에 두 번 틀리면 다음 세션으로 미룬다(같은 걸 계속 붙잡고 있지 않기).
- 이전 세션에서 헷갈렸던 개념은 다음 세션 초반에 먼저 나온다.
- 진행 상태(`exam.course`)는 카드마다 저장된다. 중간에 나가도 같은 카드에서 이어진다.

## 시험 준비도 (`core/readiness.ts`)

```
준비도 = 5 + 90 × Σ(가중치 × 숙련도) / Σ가중치      가중치 = 중요도^1.5, 숙련도 0~1
```

- 시작값 5 = 자료를 올린 것 자체에 대한 점수.
- **모든 개념**을 분모에 넣는다. 버린 개념은 중요도가 낮아 비중이 작다. 그래서 루트를 다 끝내도 100이 되지 않는 게 정상이다(정직하게).
- 숙련도는 정답(+0.25), 떠올리기 성공(+0.35), 개념 완료(+0.15), 헷갈린 개념 복습 성공(+0.25) 등으로 오른다. 틀려도 내려가지 않는다(의욕을 꺾지 않기).
- "+N 준비도"는 게이지에 보이는 숫자가 실제로 바뀐 만큼만 보여 준다.
- "오늘 N분 하면 목표 준비도"는 오늘 몫의 개념이 숙련도 0.75에 도달한다고 보고 계산한다.
- 모든 준비도 화면 아래에 "실제 시험 점수가 아니에요"를 작게 적는다.

## 자료 분석: 두 가지 방식

| | 빠른 분석 (기본) | Claude 정밀 분석 (선택) |
| --- | --- | --- |
| 필요한 것 | 없음 | Anthropic API 키 |
| 어디서 | 브라우저 안 (`core/extract.ts`) | 브라우저 → Claude API 직접 (`ai.ts`) |
| 방법 | "용어: 설명", "~란", "~는 …이다" 패턴과 등장 빈도·강조 표시(★, 중요, 시험…)·제목 등장으로 중요도 1~5. 정의가 거의 없는 글은 핵심어 빈칸 채우기로 바꿈 | 자료 전문(또는 글자 없는 스캔 PDF 원본)을 보내 개념 최대 40개와 문제를 JSON 스키마로 받음. 스트리밍, 서버측 폴백 |
| 약점 | 정의 형식이 아닌 자료에서는 문제 질이 떨어짐 | 비용이 들고 키가 브라우저에 저장됨 |

PDF 글자는 `pdf.js`로 읽는다(PDF를 고를 때만 불러옴). 글자가 거의 없는 PDF(스캔본)는 빠른 분석으로는 못 읽는다고 그대로 말한다.

체험용 **샘플**(`core/sample.ts`)은 약리학 총론·자율신경계 32개 개념을 사람이 미리 정리한 것이다. 파일도 키도 없이 전체 흐름을 볼 수 있다.

## 알려진 한계 / 다음에 할 일

1. 학생 대상 서비스라면 API 키를 학생이 넣을 수는 없다 → 작은 서버(예: Vercel 함수)에서 Claude를 호출하도록 옮기기.
2. 기록이 이 브라우저에만 있다(동기화 없음).
3. 빠른 분석은 한국어 강의노트 형식에 맞춰져 있다. 표·그림 위주 자료는 정밀 분석이 필요하다.
4. 시험 전날 밤 알림(푸시)이 없다 — "3분만"을 다시 누르게 할 가장 큰 장치.
5. 숙련도 가중치와 시간 예산은 감으로 정한 값이다. 실제 사용 기록으로 맞춰야 한다.

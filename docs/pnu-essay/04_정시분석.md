# 04. 부산대 경영학과 정시 입결 분석

> 기준: 부산대학교 정시모집 수능전형(경영학과), 2024\~2026학년도 결과와 2027학년도 전망. `❓` 표시는 공식 원문(입학처 입시결과·정시모집요강)에서 확인이 필요한 항목이다.

| 질문 | 답 |
| --- | --- |

| 안정권은 | 국·수·탐 백분위 평균 87 이상(세 영역 모두 2등급 초반 이상, 영어 1\~2등급) |
| 실채점 기준 지원 가능 점수는 | 2026학년도 국·수·탐 표준점수 합 375점, 부산대 환산 702.2점(1,000점 만점). 2025학년도 환산 700.4점 |

## 2. 정시 전형 구조 (2026학년도 정시모집요강 기준)

| 항목 | 내용 |
| --- | --- |
| 전형 방법 | 수능 100% (의예·치의학 등 일부만 수능 80 + 학업충실도 20) |
| 모집군 | 경영학과 수능전형은 가군(2025학년도 가군 경쟁률 2.92 : 1 기록). 2027학년도 군 배치는 정시요강 확인 ❓ |

| 반영 지표 | 국어·수학 표준점수, 탐구 백분위 기반 변환표준점수(2026학년도부터. 2025학년도까지는 표준점수), 영어 등급별 환산점수, 한국사 등급별 가산점 |
| 수학 선택과목 | 인문·사회계열은 제한 없음(확률과통계·미적분·기하 모두 가능) |
| 탐구 | 사회탐구·과학탐구 구분 없이 반드시 2과목 응시, 2과목 반영. 인문·사회계열 과탐 가산점 없음(일부 자연계 모집단위만 과탐 5% 가산) |

| 영어 등급별 환산점수 | 1등급 200, 2등급 198, 3등급 195, 4등급 190, 5등급 185, 6등급 180, 7등급 175, 8등급 170, 9등급 165 |

산출 예시(2026학년도 실채점 기준 지원 가능선과 같은 표준점수 합 375점):

| 영역 | 성적 | 계산 | 환산 점수 |
| --- | --- | --- | --- |
| 국어 | 표준점수 132 | 132 × 300 ÷ 200 | 198.0 |
| 수학 | 표준점수 128 | 128 × 250 ÷ 200 | 160.0 |
| 탐구 2과목 | 변환표준점수 합 115 | 115 × 250 ÷ 200 | 143.75 |
| 영어 | 1등급 | 등급 환산 | 200.0 |
| 합계 | 표준점수 합 375 | | 701.75 (+한국사 가산점) |

이 값이 부산진학지원단이 발표한 경영학과 지원 가능 환산점수 702.2점과 거의 같다. 영어는 1등급과 3등급의 차이가 5점(총점의 0.5%)에 그치므로, 당락은 사실상 국어·수학·탐구 표준점수가 결정한다.

참고: 2024학년도 84.33과 2025학년도 84.3은 수치가 거의 같다. 두 자료가 같은 해의 결과를 다른 매체가 옮긴 것일 가능성이 있으므로 입학처 입시결과 파일로 학년도를 확인해야 한다 ❓. 어느 쪽이든 "백분위 평균 84\~85가 등록자 70% 지점"이라는 결론은 바뀌지 않는다.

같은 해 다른 학과와 비교(2024학년도 70% 컷): 통계학과 82.50, 미생물학과 80.50, 중어중문학과 79.83, 문헌정보학과 78.50, 언어정보학과 73.00. 2025학년도 정시는 전체적으로 백분위 75\~78 사이에 합격선이 형성된 학과가 많았고, 의예과 99\~100, 약학부 97\~99, 간호학과 86\~88(최종등록자 50% 기준) 순이었다. 경영학과는 인문·사회계열에서 가장 높은 컷을 유지하고 있다.

## 4. 점수대별 판단 (경영학과, 국·수·탐 백분위 평균 기준)

| 백분위 평균 | 판단 | 근거 |
| --- | --- | --- |
| 88 이상 | 안정 | 최근 70% 컷보다 3점 이상 여유. 최초 합격 가능성 높음 |
| 86\~87 | 적정 | 2026학년도 사설 분석 범위(85\~87)의 상단. 최초 합격 또는 초반 충원 |
| 84\~85 | 소신 | 70% 컷(84.3) 부근. 충원 합격을 기대하는 구간 |
| 82\~83 | 도전 | 컷 아래. 해당 연도 지원자 감소나 수능 난이도 변화가 있을 때만 충원 막차 가능 |
| 81 이하 | 어려움 | 인문·사회계열 다른 학과나 지역인재전형 검토 |

주의할 점:

1. 백분위 평균은 참고 지표다. 실제 합격은 부산대 환산점수(표준점수 기반)로 결정되므로, 같은 백분위라도 국어·수학 표준점수가 높은 조합이 유리하다.
2. 수능이 어려운 해에는 표준점수가 높아져 환산 점수의 지원선(702점 안팎)이 올라가고, 쉬운 해에는 내려간다. 환산점수 지원선은 해마다 실채점 분석 자료로 다시 확인해야 한다.
3. 탐구는 2과목이 모두 25% 안에 들어가므로 한 과목만 잘 봐서는 안 된다. 사탐과 과탐의 변환표준점수 차이는 크지 않게 설계된다.
4. 지역인재전형(부산·울산·경남 고교)은 일반 수능전형보다 컷이 낮게 형성되는 경향이 있다. 해당자는 두 전형의 모집인원과 군을 비교해 지원한다.

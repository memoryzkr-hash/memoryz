## 꼭 알아야 할 사실 7가지

1. 부산대는 2028학년도부터 논술전형을 폐지한다. 2027학년도(2026년 11월 시험)가 논술로 경영학과에 들어갈 수 있는 마지막 기회다.
2. 2027학년도 논술전형은 논술 80% + 학생부 교과 20%로 논술 비중이 커졌다. 경영학과 모집인원은 18명이다.
3. 경영학과 논술 수능최저는 2개 영역 등급 합 4 이내(+한국사 4등급)로 유지된다. 다른 인문·사회계 학과는 5 이내로 완화됐지만 경영학과는 제외됐다.
4. 인문·사회계열 논술은 3문항, 문항마다 제시문 3~5개와 소문항 1~2개, 소문항당 100~300자 안팎의 약술형이다. 부산대는 "핵심 내용 포함 여부"를 먼저 보고 문장력·어휘·논리로 차등을 두며, 제시문과 무관한 선지식 답안과 글자 수 초과·미달은 감점한다고 공식적으로 밝혔다.
5. 최근 3년 논술 주제: 2024 편리한 기술의 숨은 비용·집단기억, 2025 양극화·딥페이크·기후위기, 2026 타자 혐오·능력주의·돌봄 노동. 당해 연도의 사회 이슈가 그대로 들어온다.
6. 정시 경영학과 최종등록자 70% 컷은 국·수·탐 백분위 평균 84~85(2024학년도 84.33, 2025학년도 84.3)다. 안정권은 87 이상이다. 2026학년도 실채점 기준 지원 가능선은 표준점수 합 375점, 부산대 환산 702.2점이었다.
7. 정시는 국어 30·수학 25·영어 20·탐구 25 비율의 표준점수 반영이고 영어는 등급 간 점수 차가 작다. 당락은 국어·수학·탐구 표준점수가 결정한다.

## 자료의 한계

이 세션은 네트워크가 제한되어 부산대 입학처의 논술가이드북·선행학습영향평가 보고서·입시결과 PDF 원문을 직접 열지 못했다. 검색 결과에 노출된 본문, 언론 보도, 학원·커뮤니티 공개 자료를 교차 확인해 정리했고, 원문 확인이 필요한 항목은 각 문서에 `❓`로 표시했다. 2018~2021학년도와 2023학년도 논술 문항 주제, 경영학과 정시 모집인원, 2026학년도 정시 공식 입결은 확인하지 못했으므로 각 문서의 출처 링크에서 직접 내려받아 보완해야 한다.

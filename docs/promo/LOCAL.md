# 내 컴퓨터에서 홍보 자동화 쓰기

블로그 · 인스타그램 · 쓰레드에 글을 만들어 올리고 댓글을 관리하는 에이전트를 **내 컴퓨터에서** 실행하는 방법이에요.
명령은 처음에 몇 줄만 치면 되고, 나머지(계정 등록, 글 만들기, 자동화 켜기)는 모두 브라우저 화면에서 해요.

```
npm run promo:app  →  http://localhost:4321
```

| 하는 일 | 어디서 |
| --- | --- |
| 계정 등록 (Claude 키, 쓰레드, 인스타그램, 블로그) | 화면 → **계정 연결** |
| 내 브랜드 소개 | 화면 → ⚙️ **설정** |
| 인기 글 고르기 → 글 만들기 → 지금 올리기 | 화면 → **블로그 / 인스타그램 / 쓰레드 자동화** 카드 |
| 정한 주기마다 자동으로 올리기 | 카드의 **자동화 스위치** (앱을 켜 둔 동안 15분마다 확인) |

---

## 1. 준비물 (처음 한 번)

1. **Node.js 22** 이상 — https://nodejs.org 에서 "LTS"를 받아 설치해요.
   터미널(맥: 터미널, 윈도우: PowerShell)에서 `node -v`가 `v22…` 이상이면 돼요.
2. **Git** — https://git-scm.com (맥은 터미널에서 `git`을 치면 설치 안내가 나와요).
3. 계정
   - **Anthropic API 키** (글 쓰는 AI) — https://console.anthropic.com
   - 올릴 플랫폼의 계정: 쓰레드 / 인스타그램(프로페셔널 계정) / 블로그(네이버·티스토리·워드프레스 중 하나)

## 2. 내려받고 설치 (처음 한 번)

```bash
git clone https://github.com/memoryzkr-hash/memoryz.git
cd memoryz
git checkout claude/busy-ride-ao5cgk      # 이 작업이 기본 브랜치에 합쳐졌다면 이 줄은 건너뛰어요
npm install
npx playwright-core install chromium      # 인스타그램 카드뉴스 이미지를 그릴 브라우저 (약 150MB)
```

> 압축 파일(`memoryz-promo.zip`)로 받았다면 `git clone` 대신 압축을 풀고 그 폴더에서 `npm install`부터 하면 돼요.
>
> 이미 크롬이 있고 브라우저를 또 받기 싫다면 마지막 줄 대신 `.env`에 `PROMO_CHROMIUM_PATH=크롬 실행 파일 경로`를 적어요.

## 3. 실행

```bash
npm run promo:app
```

`홍보 자동화가 켜졌어요 → http://localhost:4321`이 나오면 브라우저에서 그 주소를 열어요.
**터미널 창을 닫으면 앱도 멈춰요.** 다음부터는 `cd memoryz` 후 `npm run promo:app`만 하면 돼요.

포트를 바꾸려면 `PROMO_PORT=5000 npm run promo:app` (윈도우 PowerShell: `$env:PROMO_PORT=5000; npm run promo:app`).

## 4. 계정 등록 — 화면의 **계정 연결**

처음 화면 위쪽의 `블로그 · 인스타그램 · 쓰레드` 칩이나 **계정 연결 ›**을 눌러요.
등록 버튼을 누르면 앱이 그 서비스에 실제로 접속해 토큰이 맞는지 확인한 뒤 저장해요. 틀리면 이유를 알려 주고 저장하지 않아요.
저장된 값은 **이 폴더의 `.env` 파일**에만 들어가요(git에 올라가지 않고, 이 컴퓨터 밖으로 나가지 않아요).

### ① 글 쓰는 AI (Claude) — 필수
1. https://console.anthropic.com 가입 → 결제 수단 등록
2. **Settings → Limits**에서 월 사용 한도를 꼭 정해요 (예: $20)
3. **API Keys → Create Key**로 만든 `sk-ant-…` 키를 붙여넣고 **등록**

### ② 쓰레드
1. https://developers.facebook.com/apps 에서 **앱 만들기** → 사용 사례 **Threads API 액세스**
2. 권한 추가: `threads_basic`, `threads_content_publish`, `threads_read_replies`, `threads_manage_replies`
3. **앱 역할 → 역할**에서 내 쓰레드 계정을 **Threads 테스터**로 추가 → 쓰레드 **설정 → 계정 → 웹사이트 권한 → 초대**에서 수락
4. **사용자 토큰 생성기**에서 만든 토큰(60일짜리)을 붙여넣고 **등록**

### ③ 인스타그램
1. 인스타그램 앱 **설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환** (개인 계정은 API로 못 올려요)
2. 같은 메타 앱에 **Instagram** 제품을 추가하고 **Instagram 로그인을 통한 API 설정**을 열어요
3. 권한: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_comments`
4. **앱 역할**에 내 계정을 **Instagram 테스터**로 추가 → 인스타그램 웹 **설정 → 앱 및 웹사이트 → 테스터 초대** 수락
5. **액세스 토큰 생성**에서 만든 토큰을 붙여넣고 **등록**

쓰레드·인스타그램 토큰은 60일 뒤 만료되는데, 앱이 일주일마다 알아서 연장해요(연장된 토큰은 암호화돼 `.promo-data`에 보관).
그래도 앱을 60일 넘게 한 번도 안 켰다면 토큰을 새로 받아 **바꾸기**로 다시 넣어요.

### ④ 카드 이미지 저장소 — 인스타그램을 쓸 때만
인스타그램은 이미지를 **인터넷 주소**에서 가져가요. 그래서 내 컴퓨터에서 만든 카드 이미지를 공개 GitHub 저장소에 올려서 그 주소를 넘겨요.
1. GitHub에서 **공개(Public)** 저장소를 하나 만들어요 (예: `promo-media`, 비어 있어도 돼요)
2. https://github.com/settings/personal-access-tokens 에서 **그 저장소만** 골라 **Contents: Read and write** 토큰을 만들어요
3. `내아이디/promo-media`와 토큰을 넣고 **등록**

### ⑤ 블로그
**어떤 블로그인가요?**에서 골라요.
- **네이버 블로그 / 티스토리** — 등록할 것이 없어요. 두 곳 모두 글쓰기 API가 닫혀 있어서(네이버 2020년 5월 종료), 앱이 **붙여넣기용 글**을 만들어 주고 제목·본문·태그 **복사** 버튼으로 옮겨 붙여요. 붙여넣은 뒤 **완료로 표시**를 눌러요.
- **워드프레스** — 블로그 주소(`https://…`), 로그인 아이디, **애플리케이션 비밀번호**(관리자 → 사용자 → 프로필 → 애플리케이션 비밀번호에서 새로 만들기, 로그인 비밀번호 아님)를 넣고 **등록**. 그 뒤로는 자동으로 올라가요.

## 5. 내 브랜드 — ⚙️ **설정**

모든 글은 여기 적은 내용으로 써요. 예시 브랜드(단백한끼)를 지우고 내 것으로 바꿔요.
- 브랜드 이름, 대표 계정(카드 이미지 아래 들어가요), 브랜드 소개(무엇을, 누구에게, 어떤 말투로, 꼭 강조할 것·하지 말 것)
- **자동으로 만든 글은 내가 확인한 뒤 올리기** — 처음 1~2주는 켜 두는 걸 권해요. 켜 두면 자동화가 만든 글이 "확인 대기"로 남고, 화면에서 확인 후 **지금 올리기**를 눌러야 올라가요.

## 6. 글 만들기 — 플랫폼 카드 → **글 만들기**

1. **인기 글 고르기**: 주제를 넣고 **인기 글 찾기**(1~3분). 반응 좋은 글이 스크롤 피드로 나와요 — 시작 문장(후킹), 구성, 잘 되는 이유가 정리돼 있어요.
   마음에 드는 글을 **이 글 참고하기**로 골라요(최대 5개).
   인스타·쓰레드 글은 로그인해야 보여서 검색에 잘 안 잡혀요. 직접 본 인기 글은 **내가 찾은 인기 글 넣기**에 본문을 붙여넣으면 앱이 분석해서 피드에 넣어요.
2. **글 만들기**: 고른 글의 시작 방식과 구성을 따라 내 브랜드로 새로 써요(문장은 베끼지 않아요). 2~5분 걸려요.
3. 나온 글을 고치고 **지금 올리기**. (네이버·티스토리는 복사해서 붙여넣기)

## 7. 자동화 — 카드의 스위치

스위치를 켜고 주기(매일 · 평일 · 주 3회 · 주 2회 · 주 1회 · 요일 직접)와 시간을 골라요. 플랫폼마다 따로예요.
앱이 **15분마다** 올릴 차례인지 보고, 차례가 되면 주제를 정해 → 인기 글을 참고해 → 쓰고 → 검사한 뒤 올려요. 같은 때 새 댓글도 확인해서 칭찬·FAQ로 답할 수 있는 질문에는 답글을 달고, 스팸은 숨기고, 불만·민감한 댓글은 **직접 답할 댓글**로 남겨요.

> ⚠️ **앱(터미널)과 컴퓨터가 켜져 있을 때만** 올라가요. 꺼져 있는 동안 지난 차례는 6시간 안이면 켜자마자 올리고, 그보다 오래되면 건너뛰어요(`promo/config.yml`의 `catchUpHours`).
> 컴퓨터를 꺼도 올라가게 하려면 GitHub Actions로 옮겨요 → [SETUP.md](SETUP.md)의 "가장 쉬운 방법".

## 파일 지도

```
memoryz/
├─ .env                     ← 등록한 키·토큰 (앱이 만들어요, git에 안 올라가요, 절대 공유 금지)
├─ .env.example             ← .env에 들어가는 이름 목록
├─ promo/                   ← 내 설정 (화면에서 바꾸면 여기에 저장돼요, 직접 고쳐도 돼요)
│  ├─ config.yml            ← 플랫폼별 자동화 on/off·주기, 금지어, 댓글 처리 규칙, 해시태그
│  ├─ brand.md              ← 브랜드 소개 (글의 바탕)
│  ├─ faq.md                ← 댓글 답글에 쓰는 자주 묻는 질문
│  ├─ references.md         ← 늘 참고할 계정·글 주소
│  └─ templates/            ← 플랫폼별 글 구성 (blog.md · instagram.md · threads.md)
├─ .promo-data/             ← 앱이 쌓는 기록 (앱이 만들어요)
│  ├─ drafts/               ← 만든 글 (마크다운)
│  ├─ references/           ← 찾은 인기 글
│  ├─ media/                ← 카드뉴스 이미지
│  ├─ state.json            ← 올린 글·처리한 댓글 기록
│  ├─ inbox.md              ← 직접 답해야 할 댓글
│  └─ report.md             ← 마지막 실행 보고서
├─ src/promo/               ← 에이전트 코드
│  ├─ server.ts             ← npm run promo:app (화면 + 로컬 API + 15분 스케줄러)
│  ├─ cli.ts                ← npm run promo -- <명령>
│  ├─ agent.ts              ← 주제 → 레퍼런스 → 글 → 검사 → 발행, 댓글 처리
│  ├─ ai/                   ← Claude 호출과 프롬프트
│  ├─ platforms/            ← 쓰레드 · 인스타그램 · 워드프레스 · 네이버(붙여넣기)
│  ├─ media/                ← 카드뉴스 이미지 그리기·올리기
│  └─ ui/                   ← 화면 (promo.html)
└─ docs/promo/              ← PLAN.md(기획서) · SETUP.md(GitHub 버전) · LOCAL.md(이 문서)
```

백업할 것은 `promo/`, `.promo-data/`, `.env` 세 가지예요. 다른 컴퓨터로 옮길 때도 이 셋을 복사하면 돼요.

## 터미널 명령 (선택)

화면 없이 쓰거나 확인할 때:

```bash
npm run promo -- check                                    # 등록한 계정이 모두 동작하는지 확인
npm run promo -- preview --topic "점심 단백질 30g 채우기"   # 올리지 않고 글만 만들기 → .promo-data/drafts/
npm run promo -- post-now --platform threads --topic "…"  # 지금 바로 만들어 올리기 (blog | instagram | threads)
npm run promo -- research --topic "…"                     # 인기 글만 찾기 → .promo-data/references/
npm run promo -- comments                                 # 댓글만 처리
npm run promo -- run                                      # 정기 실행 한 번 (차례가 된 것만)
npm run promo -- run --dry-run                            # 올리지 않고 흉내만
```

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| `npm run promo:app`에서 `loadEnvFile is not a function` | Node가 오래됐어요. Node 22 이상을 설치해요. |
| 포트가 이미 쓰이고 있다고 나옴 | 앱이 이미 켜져 있거나 다른 프로그램이 4321을 써요. `PROMO_PORT=5000 npm run promo:app` |
| 화면이 "미리보기"로 나옴 | `localhost:4321`이 아닌 다른 주소(GitHub Pages, claude.ai 링크)로 연 거예요. 앱을 켠 터미널에 나온 주소로 열어요. |
| 등록 시 `권한이 없어요` | 토큰을 다시 복사했는지, 4번의 권한(scope)이 모두 들어갔는지 확인해요. 권한을 추가했다면 토큰을 새로 받아야 해요. |
| 등록 시 `인터넷 문제로 확인하지 못했지만 저장했어요` | 저장은 됐어요. 인터넷이 되는 상태에서 `npm run promo -- check`로 다시 확인해요. |
| 카드 이미지 오류 `Executable doesn't exist` | `npx playwright-core install chromium`을 실행하거나 `.env`에 `PROMO_CHROMIUM_PATH`를 적어요. |
| 인스타그램 `이미지 주소가 공개되지 않았어요` | 4-④ 카드 이미지 저장소가 **공개** 저장소인지 확인해요. |
| 자동화가 안 올라감 | 앱이 켜져 있는지, 카드에 "다음 게시 …"가 보이는지, 설정의 "확인한 뒤 올리기"가 켜져 있어 확인 대기에 쌓였는지 봐요. |
| 글이 "검수에서 막힘" | 글 화면 맨 위의 이유를 봐요. `promo/config.yml`의 금지어가 너무 넓거나, `brand.links`에 없는 링크를 쓰려는 경우가 많아요. |
| 처음부터 다시 | 앱을 끄고 `.promo-data/`를 지우면 기록이 초기화돼요(`.env`의 계정은 남아요). |

더 자세한 토큰 발급 화면 설명(페이스북 로그인 방식 인스타그램 포함)은 [SETUP.md](SETUP.md) 3~5번에 있어요.

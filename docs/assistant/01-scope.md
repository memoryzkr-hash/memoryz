# 01 범위 — 개인 비서 (`assistant.html`)

> 연습 계획 [PRACTICE_PLAN.md](../PRACTICE_PLAN.md)의 1단계 결과입니다. 2단계부터는 이 문서를 기준으로 진행합니다.

## 한 줄 설명
내가 정한 주제의 **최신 소식만 골라 요약**해 주고, 말로 적은 **일정을 정리**해 주고,
**보낼 메시지 초안**을 써 주는 나만의 비서 웹앱.

## 핵심 기능 (v1, 3개)

### 1. 최신 소식 브리핑
- 관심 주제를 최대 5개 등록합니다 (예: "AI 도구", "부동산 정책", "클래시로얄 업데이트").
- **브리핑 받기**를 누르면 Claude가 웹을 검색해 주제별로 3~5줄 요약과 출처 링크를 보여 줍니다.
- 지난 브리핑은 날짜별로 저장되어 다시 볼 수 있습니다.

완료 조건
- [ ] 주제 2개를 등록하고 **브리핑 받기**를 누르면, 진행 중 표시가 보이고 1분 안에 주제별 요약이 나온다.
- [ ] 요약마다 누를 수 있는 출처 링크가 1개 이상 붙어 있다.
- [ ] 새로고침해도 주제 목록과 오늘 브리핑이 그대로 있다.
- [ ] API 키가 틀리거나 인터넷이 끊기면 빈 화면이 아니라 이유가 적힌 오류 문구가 보인다.

### 2. 일정 관리
- "다음 주 화요일 3시 강남역에서 민수랑 미팅"처럼 말하듯 적으면 Claude가 제목·날짜·시간·장소로 나눠 **확인 카드**를 보여 줍니다.
- 확인을 눌러야 저장됩니다 (AI가 날짜를 잘못 읽어도 저장 전에 고칠 수 있게).
- 오늘 / 이번 주 목록으로 보고, 수정·삭제할 수 있습니다.
- **공유**: 일정마다 공유 버튼 → ① 캘린더 파일(`.ics`) 내려받기 ② 3번 기능으로 "일정 알리는 메시지" 쓰기.

완료 조건
- [ ] 위 예시 문장을 넣으면 확인 카드에 실제 다음 주 화요일 날짜와 15:00이 채워져 있다.
- [ ] 확인 카드에서 시간을 고친 뒤 저장하면, 목록에 고친 시간으로 보인다.
- [ ] 공유 → `.ics` 파일을 받아 휴대폰/구글 캘린더에서 열면 같은 일정이 추가된다.
- [ ] 새로고침 후에도 일정이 남아 있다.

### 3. 메시지 초안
- 받는 사람(관계: 상사, 친구, 가족 등), 하고 싶은 말, 말투(정중 / 편하게)를 고르면 초안 2개를 써 줍니다.
- **복사** 버튼으로 카톡·문자·메일에 바로 붙여 넣습니다.
- 일정의 공유 버튼에서 들어오면 일정 정보가 미리 채워진 상태로 시작합니다.

완료 조건
- [ ] "팀장님께 내일 오후 반차 쓴다고 정중하게"를 넣으면 서로 다른 초안 2개가 나온다.
- [ ] **복사**를 누르면 "복사됨" 표시가 뜨고, 카톡 입력창에 붙여 넣으면 그대로 들어간다.
- [ ] 일정 공유에서 시작하면 날짜·시간·장소가 초안에 들어가 있다.

## 결정 사항

| 항목 | 결정 | 메모 |
| --- | --- | --- |
| 위치 | `assistant.html` + `src/assistant/` + `tests/assistant/` | Royale, 네온 라이더와 같은 방식. `/memoryz/assistant.html`로 배포 |
| AI 연결 | 처음 열 때 **내 Anthropic API 키**를 입력, 브라우저(`localStorage`)에만 저장 | 키는 절대 코드·저장소에 넣지 않음. Anthropic 콘솔에서 **월 사용 한도**를 꼭 걸어 둘 것 |
| 모델 | `claude-opus-5-5` | 메시지 초안처럼 가벼운 일은 effort를 낮춰 비용 절약 |
| 최신 소식 | Claude의 웹 검색 도구(`web_search_20260209`)로 검색 | 브라우저에서 뉴스 사이트를 직접 긁으면 CORS에 막히므로, 검색은 Claude 쪽에서 함 |
| 저장 | `localStorage` (주제, 브리핑 기록, 일정) | 브라우저를 지우면 같이 지워짐 → v1의 알려진 한계 |
| 일정 공유 | `.ics` 파일 + 공유 메시지 | 질문에서 "다른 사람과 공유"를 골랐지만 서버 없는 연결 방식과 충돌해서, v1은 서버 없이 되는 방법으로 정함 |

## 비용 메모
- 브리핑 1번 = Claude 호출 + 웹 검색 여러 번. **토큰 요금에 검색 건당 요금이 따로 붙습니다** (정확한 금액은 Anthropic 가격 페이지 확인).
- 주제당 검색 횟수를 제한(`max_uses`, 예: 3회)해서 한 번 누를 때 비용이 튀지 않게 합니다.
- 일정 해석·메시지 초안은 검색 없이 짧은 호출이라 훨씬 쌉니다.

## 2단계 전에 정한 것
1. 관심 주제 예시: **AI 도구, 주식, 게임 업데이트** (화면 설계와 테스트 데이터에 씀. 실제 주제는 앱에서 직접 등록)
2. 브리핑 언어: **한국어 기사 + 영어 기사**를 모두 찾고, 요약은 항상 한국어. 영어 출처는 `[EN]` 표시

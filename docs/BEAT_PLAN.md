# 비트 바운스 — 박자에 맞춰 튀는 리듬 플랫포머 기획서

## 한 줄 소개
공이 음악 박자에 맞춰 저절로 앞으로 굴러가고, 플레이어는 **박자에 맞춰 눌러서** 가시·구멍·계단을 뛰어넘는다.
지오메트리 대시처럼 **한 번 닿으면 처음부터**, 바운스볼처럼 **통통 튀는 공**, 리듬 게임처럼 **누를 때마다 PERFECT/GREAT/GOOD 판정**.

## 레퍼런스에서 가져온 것
| 레퍼런스 | 가져온 것 | 비트 바운스에서 |
| --- | --- | --- |
| 지오메트리 대시 | 자동 전진, 원 버튼, 죽으면 즉시 재시작, 시도 횟수, 진행률 %, 점프 발판·공중 링 | 그대로. 단, 모든 장애물이 박자 격자 위에 있다 |
| 바운스볼 | 통통 튀는 공 캐릭터, 계단을 밟고 오르는 맛 | 땅 위에서 공이 박자마다 찌그러졌다 튄다. 계단 오르기·내려가기 |
| 리듬 게임 (osu!, 리듬 세상) | 정확도 판정, 콤보, 다가오는 링, 싱크 보정 | 누를 박자가 다가오면 공 둘레에 링이 줄어들며 겹친다 |

## 핵심 재미
1. **음악이 곧 맵이다** — 눌러야 하는 박자마다 멜로디 음이 나온다. 노래를 따라 부르듯 누르면 장애물을 넘는다.
2. **한 번 더!** — 0.9초 만에 재시작. "이번엔 63%까지 갔다"가 다음 판을 부른다.
3. **잘 맞췄다는 손맛** — 판정 글자, 착지 먼지, 박자마다 쿵 하는 배경 숫자와 화면 울림.

## 조작
| 입력 | 동작 |
| --- | --- |
| Space · ↑ · W · 마우스 클릭 · 화면 터치 | 점프 (땅에 있을 때) |
| 누르고 있기 | 착지하자마자 계속 점프 (지오메트리 대시와 같음) |
| 공중의 링에 닿았을 때 누르기 | 공중에서 한 번 더 점프 |
| Esc · P · 일시정지 버튼 | 일시정지 (오디오 시계도 멈춤) |

누르기는 0.15박 동안 기억된다(입력 버퍼). 착지 직전에 살짝 먼저 눌러도 점프가 나간다.

## 물리 (단위: 칸, 박자)
시간을 **초가 아닌 박자**로 계산한다. BPM이 달라도 같은 맵이 똑같은 박자 감각으로 플레이되고, 장애물 배치가 곧 악보가 된다.

| 수치 | 값 | 의미 |
| --- | --- | --- |
| 전진 속도 | 4칸/박 | 8분음표 하나 = 2칸 |
| 점프 | 1박 체공, 높이 2.2칸 | 박자에 누르면 다음 박자에 착지 |
| 노란 발판 | 1.5박 체공, 높이 약 5칸 | 누르지 않아도 되는 "쉬는 박자" |
| 공중 링 | 그 자리에서 점프 1번 더 | 엇박 리듬 |
| 시뮬레이션 | 1/240박 고정 스텝 | 결정적 → 단위 테스트로 모든 맵을 자동 검증 |

판정 상자는 그림보다 조금 작다(공 반지름 0.4 → 가시 판정 0.32). 억울한 죽음을 줄이기 위해서다.

## 맵 만들기: 악보 → 지형
맵은 지형을 직접 그리지 않고 **"몇 번째 박자에 무엇을 누르는가"** 로 적는다. 한 줄이 한 마디(8분음표 8칸)다.

```
2 1...1...   ← 첫 글자는 이 마디의 음악 세기(0~3), 그 뒤 8칸
3 2...u...
```

| 글자 | 뜻 | 누르기 |
| --- | --- | --- |
| `.` | 아무것도 없음 | |
| `1` `2` `3` | 가시 1·2·3개를 뛰어넘기 | 이 박자에 누름 |
| `_` | 구멍(2칸) 뛰어넘기 | 누름 |
| `u` | 한 칸 높은 계단으로 뛰어오르기 | 누름 |
| `d` | 한 칸 아래로 떨어지기 | 자동 |
| `^` | 노란 발판 + 그 아래 가시밭 | 자동 |
| `o` | 공중 링 + 그 아래 구멍 | 공중에서 누름 |

**맵 빌더**는 "정답대로 누르는 가상 플레이어"를 실제 물리로 굴려 가며, 그 공이 가장 높이 뜬 지점 밑에 가시를 놓는다.
그래서 정답 박자에 누르면 장애물 한가운데를 넘게 되고, 앞뒤 허용 오차가 똑같다.

테스트가 모든 스테이지에 대해 확인하는 것:
- 정답 박자대로 누르면 끝까지 살아서 클리어하고 전부 PERFECT
- 아무것도 안 누르면 죽는다 / **누르는 박자 하나만 빼먹어도 죽는다** (공짜 노트 없음)
- 누르는 박자 하나를 앞뒤로 조금(스테이지별 허용 오차) 어긋나게 눌러도 살아남는다

## 판정
| 판정 | 오차 | 점수 |
| --- | --- | --- |
| PERFECT | ±45ms 이내 | 100% |
| GREAT | ±90ms 이내 | 70% |
| GOOD | 그보다 크지만 살아남음 | 40% |
| MISS | 눌러야 할 박자를 그냥 지나침 | 0% |

- GREAT·GOOD에는 "빠름/느림"을 같이 보여 준다.
- 정확도 = 판정 점수 평균. 등급: S(95%↑, MISS 없음) · A(85%↑) · B(70%↑) · C.
- 오디오 시계가 기준이다: 소리가 실제로 스피커에서 나오는 시각(`getOutputTimestamp`)으로 박자를 계산하고,
  키 입력도 입력 이벤트 시각으로 박자에 맞춘다(프레임 단위 오차 없음).
- **싱크 조절**: 설정에서 메트로놈에 맞춰 8번 두드리면 평균 오차로 자동 보정, ±150ms 수동 조절도 가능. 블루투스 이어폰용.

## 스테이지
| # | 이름 | BPM | 길이 | 새로 나오는 것 |
| --- | --- | --- | --- | --- |
| 1 | 첫 박자 | 108 | 32마디 | 가시 1·2개, 구멍, 계단, 노란 발판 |
| 2 | 계단 도시 | 124 | 36마디 | 연속 계단, 가시 3개, 공중 링 |
| 3 | 더블 타임 | 140 | 40마디 | 링 연속, 엇박, 쉬지 않는 점프 |

- 음악은 파일 없이 WebAudio로 합성한다(킥·스네어·하이햇·베이스·코드 패드). 마디마다 세기(0~3)에 따라 악기가 늘어난다.
- 눌러야 하는 박자마다 멜로디 음, 발판에는 위로 솟는 효과음 → **맵을 귀로 들을 수 있다.**
- 4박 카운트인 동안 공이 굴러 들어온다.

## 모드
- **일반**: 죽으면 처음부터. 최고 진행률과 최고 등급을 브라우저에 저장.
- **연습**: 16박(4마디)마다 체크포인트. 죽으면 한 마디 카운트인(딸깍 4번) 뒤 마지막 체크포인트부터 음악과 함께 이어 간다. 기록은 저장하지 않는다.
- **박자 가이드**(기본 켬): 누를 박자 0.75박 전부터 공 둘레에 링이 줄어든다. 바닥에는 박자 눈금, 누를 자리에 화살표.

## 화면
- **타이틀 = 앨범 트랙리스트**: 뒤에서 1스테이지 데모가 그대로 보이고, 오른쪽(폰은 아래)에 트랙 목록.
  트랙마다 번호·이름·난이도·BPM·곡 길이·기록(등급 배지 또는 최고 %). 아직 못 깬 첫 트랙에 "처음이면 여기/다음" 표시와 포커스.
  한 번 누르면 바로 시작, ↑↓로 고르고 Enter. 설정(박자 가이드·연습·싱크·소리)은 목록 아래 칩으로.
- **플레이**: 위쪽에 곡 전체 진행 바(최고 기록·체크포인트 표시), %, 시도, 정확도. 콤보는 가운데 위에서 늘 때마다 톡 튄다.
  아래 가운데 **타이밍 막대**: 최근 12번 누른 위치가 빠름←정박→느림으로 찍힌다. 배경의 큰 박자 숫자와 땅 윗선이 박자마다 빛난다.
- **처음 3번 시도 안내**: 종류별 첫 장애물 위에 말풍선("박자에 맞춰 탭!", "링 안에서 한 번 더 탭", "노란 발판은 자동 점프" 등).
- **죽음**: 공이 조각으로 터지고 음악이 끊긴다. 가운데 크게 "63%"와 "최고 72%/최고 기록!" → 0.9초 뒤 자동 재시작, **누르면 바로 재시작**.
- **클리어**: 등급, 정확도, 판정별 개수, 최고 콤보, 시도 횟수, **타이밍 분포 그래프와 평균 오차**.
  평균이 25ms 넘게 한쪽으로 쏠리면 "싱크 조절로 맞추기" 링크. 다시 하기 · 다음 스테이지 · 스테이지 선택.
- 스테이지마다 색이 다르다: 1 주황 하늘 + 남색 땅, 2 청록 하늘 + 자두색 땅, 3 진홍 하늘 + 검보라 땅.

## 기술 구조
기존 저장소(Vite + TypeScript)에 네 번째 페이지 `beat.html`로 추가한다. 외부 라이브러리 없이 Canvas 2D + WebAudio.

```
beat.html                진입 페이지 (오버레이 DOM)
src/beat/
  core/                  순수 로직 (DOM 없음 → 단위 테스트)
    constants.ts           물리·판정 수치
    physics.ts             공 물리, 블록·가시·발판·링 충돌, 입력 버퍼
    chart.ts               악보 문자열 → 지형 + 노트 (가상 플레이어로 배치)
    judge.ts               판정, 콤보, 정확도, 등급
    levels.ts              스테이지 3개 (악보 + 음악 설정 + 색)
  audio/music.ts         합성 악기, 박자 스케줄러, 오디오 시계, 효과음
  render/draw.ts         캔버스 그리기 (카메라, 지형, 공, 이펙트, HUD)
  ui/overlays.ts         타이틀·일시정지·결과·싱크 조절 화면
  main.ts                상태 머신: 타이틀(데모) → 카운트인 → 플레이 → 죽음/클리어
tests/beat/              physics / chart(모든 스테이지 검증) / judge 테스트
```

# 클로드 사용량 관리 (`usage.html`) 기획서

## 한 줄 설명
클로드 계정을 여러 개 등록해 두고, **계정마다 다음 초기화가 언제인지**와 **그때까지 몇 %를 썼는지**를
한 화면에서 보고, 지금 어느 계정을 쓰는 게 좋은지 알려 주는 웹앱.

## 왜 필요한가
- 클로드 구독(Pro · Max)은 **5시간 세션 한도**와 **주간 한도** 두 가지가 있고, 주간 한도는 계정마다 초기화 요일·시각이 다릅니다.
- 계정이 2개 이상이면 "어느 계정이 언제 풀리는지", "이번 주에 얼마나 남았는지"를 매번 로그인해서 확인해야 합니다.
- 곧 초기화되는데 많이 남은 계정을 안 쓰면 그만큼 버려지고, 반대로 한 계정만 쓰면 주 중간에 막힙니다.

## 핵심 기능

### 1. 계정 등록
- 이름(별칭), 이메일(선택), 요금제(Pro / Max 5x / Max 20x / Team / 기타), 메모.
- **주간 초기화 시각**: claude.ai → 설정 → 사용량에 나온 시각을 한 번만 넣으면 됩니다.
  날짜·시각으로 넣거나 "3일 4시간 후"처럼 남은 시간으로 넣을 수 있습니다.
  지난 시각이 되면 자동으로 7일씩 넘어갑니다.
- **결제 갱신일**(선택): 매달 며칠인지. D-day로 보여 줍니다.

### 2. 사용량 기록
- 주간 사용량 %, 5시간 세션 사용량 %와 세션 남은 시간을 넣습니다.
- 카드에서 **사용량 수정**을 누르면 바로 숫자만 고칠 수 있습니다(슬라이더 + 숫자).
- **붙여넣기로 업데이트(실험적)**: claude.ai에서 북마클릿을 누르면 사용량이 클립보드에 복사되고,
  관리 페이지에 붙여 넣으면 주간·세션 %와 초기화 시각이 한 번에 채워집니다.
  claude.ai의 공개되지 않은 내부 주소를 쓰므로 언제든 바뀔 수 있고, 그때는 직접 입력하면 됩니다.
  로그인 정보(쿠키·토큰)는 복사하지도 저장하지도 않습니다.

### 3. 한눈에 보기
계정 카드마다:
- 주간 사용량 막대 + **지금 시점 기준선**(주간 중 흐른 시간 %). 막대가 기준선보다 길면 빨리 쓰는 중.
- 초기화 시각과 남은 시간("10/11(토) 09:00 · 2일 14시간 남음").
- **예상치**: 지금 속도대로면 초기화 때 몇 %가 되는지.
- 상태 표시: 여유 · 적정 · 과속(초기화 전에 소진 예상) · 소진 · 곧 초기화(남은 양이 많음) · 입력 필요.
- 세션 한도: 사용 % + 풀리는 시각, 끝났으면 "새 세션 가능".
- 마지막 업데이트가 12시간 넘었으면 흐리게 + "오래된 값" 표시.

### 4. 지금 쓸 계정 추천
- 주간 한도가 남아 있고 세션이 막히지 않은 계정 중, **남은 % ÷ 초기화까지 남은 시간**(시간당 써도 되는 양)이 가장 큰 계정을 추천합니다.
  곧 초기화되는데 많이 남은 계정이 먼저 나옵니다.
- 정렬: 초기화 임박순 / 남은 양 많은 순 / 이름순.

## 자동 조회 (맥)
- `tools/claude-usage` zsh 스크립트: 계정마다 `claude setup-token`으로 받은 토큰을 키체인에 저장하고, `claude-usage` 한 줄로 전 계정을 조회해 JSON을 클립보드에 복사합니다.
- 페이지는 그 JSON을 붙여 넣으면 계정 이름(또는 이메일)으로 맞춰 한 번에 반영합니다. 로그인 정보(아이디·비밀번호)는 어디에도 받지 않습니다.
- 디자인: 한 열 카드, 계정마다 "계정 N · 이름", 주간 한도와 5시간 세션 게이지에 기간(시작 ~ 초기화)과 남은 시간을 표시합니다.

## 로컬 실행 (맥)
- `local/claude-usage/` 폴더: `index.html`(더블클릭으로 여는 페이지), `claude-usage`, `install.sh`, `README.md`.
- `claude-usage`가 조회할 때마다 같은 폴더에 `usage-data.js`를 쓰고, `file://`로 열린 페이지가 그것을 1분마다(또는 버튼·창 복귀 시) 읽어 반영합니다. 같은 조회 결과는 두 번 반영하지 않습니다.

## 저장
- claude.ai 아티팩트로 열면 **클라우드 저장**(어느 기기에서나 같은 목록, 본인만 읽고 쓰기).
- 그 밖(로컬 `npm run dev`, GitHub Pages)에서는 **이 브라우저에만 저장**(localStorage).

## 완료 조건
- [ ] 계정 2개를 등록하고 새로고침해도 그대로 있다.
- [ ] 주간 초기화 시각을 어제로 넣으면 6일 뒤 같은 시각으로 표시되고 "초기화됨 · 업데이트 필요"가 보인다.
- [ ] 주간 50%, 기간의 25%가 지난 계정은 "과속", 예상치 200%로 보인다.
- [ ] 곧 초기화되는데 많이 남은 계정이 추천 1순위로 나온다.
- [ ] 세션 100%인 계정은 추천에서 빠지고 "세션 한도 · HH:MM 이후"가 보인다.
- [ ] 휴대폰 폭(400px)에서도 가로 스크롤 없이 보인다.

## 구조
```
src/usage/core.ts   순수 계산: 주간 롤오버, 진행률·예상치·상태, 추천, 결제일, 붙여넣기 파싱, 시간 표시
src/usage/store.ts  저장소: 클라우드(아티팩트 db) / 브라우저(localStorage)
src/usage/main.ts   화면
tests/usage/        core 단위 테스트
scripts/build-usage-artifact.mjs   한 파일짜리 아티팩트 HTML로 묶기
```

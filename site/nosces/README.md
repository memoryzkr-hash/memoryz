# 노스케스 웹사이트 (nosces.com)

블라인더와 줄줄을 소개하는 회사 사이트예요. 파일 하나(`index.html`)와 이미지 폴더(`img/`)가 전부이고, 빌드 과정이 없어요.

- 실제 사이트: https://nosces.com (Cloudflare)
- 원본 파일: GitHub `memoryzkr-hash/memoryz` 저장소, `claude/wizardly-pasteur-l3s24q` 브랜치의 `site/nosces/`
  - 2026-10-08 기준으로 nosces.com에 올라가 있는 내용과 같아요.
- 배포: Cloudflare에서 `index.html`과 `img/` 폴더를 통째로 올려요. `img/`를 빼고 올리면 회사 소개의 사진이 사라져요.

## 화면 구성

페이지는 하나이고, 주소 끝의 `#`으로 화면을 바꿔요.

| 주소 | 화면 | HTML 위치 |
|---|---|---|
| `#home` (기본) | 홈: 큰 타일 2개(블라인더, 줄줄) → 넘겨 보는 타일 4개 → "나에게 맞는 앱은?" 비교표 | `<div class="view" id="v-home">` |
| `#blinder` | 블라인더 소개 | `v-blinder` |
| `#juljul` | 줄줄 소개 | `v-juljul` |
| `#about`, `#about-en` | 회사 소개(한국어, 영어) | `v-about` |
| `#support` | 고객지원: 자주 묻는 질문, 문의 메일, 약관 링크 | `v-support` |
| `#refund` | 블라인더 환불 정책 (사이트 안 사본) | `v-refund` |

- **화면 안 구역**: `#blinder-price`처럼 `화면-구역`으로 쓰면 그 화면을 열고 해당 `id`로 스크롤해요.
- **화면 전환 코드**: 맨 아래 `<script>`의 `route()` 함수예요. 화면 이름은 `#` 뒤에서 `-` 앞까지예요.
- **화면마다 바뀌는 값**: 바닥글 각주는 `NOTES`, 바닥글 경로 표시는 `CRUMB` 객체에 있어요.

## 제품 페이지 순서 (블라인더·줄줄 공통)

1. 제품 메뉴(`.lnav`): 앱 이름과 시작 버튼이 있어요.
   - 컴퓨터용 구역 버튼은 `.lls`, 휴대폰용 ⌄ 펼침 목록은 `.lsheet`예요.
2. 첫 화면(`.hero`): 기기 틀 안에서 직접 해 보는 체험이 있어요. 줄줄은 휴대폰 틀(`.phone`), 블라인더는 태블릿 틀(`.tablet`)이에요.
3. 대표 기능(`.band.gray`): 블라인더는 그림 자동 찾기, 줄줄은 6단계예요.
4. 기능 타일 4개(`.tiles.swipe`): 휴대폰에서는 옆으로 넘겨 보는 카드가 되고, 아래에 점이 자동으로 생겨요.
5. 숫자로 보는 앱(`.stats`)
6. 세 단계 쓰는 방법(`.steps3`)
7. 검은 구역(`.band.dark`): 블라인더는 "웹에서도, 아이폰에서도", 줄줄은 "가입 없이, 바로 시작해요"예요.
8. 요금(`.cmp`): 3칸이에요.
9. 마지막 안내(`.band.dark`): 다른 앱으로 가는 링크가 있어요.

## 공통 부분

- **맨 위 메뉴** `header.gnav`
  - 제품마다 `<li class="has-fly">`가 있고, 마우스를 올리면 펼침 메뉴(`.fly`)가 나와요.
  - 휴대폰 ☰ 메뉴는 `#msheet`이고, `header` 바로 다음에 있어요. 머리글 안에 넣으면 화면을 다 덮지 못하니 밖에 두세요.
- **로고**: `<span class="logo-s">`(줄줄), `<span class="logo-b">`(블라인더)를 넣으면 스크립트가 `LOGO_S`, `LOGO_B` SVG로 바꿔 줘요.
- **바닥글** `footer`
  - 각주: `#notes`
  - 목록 칸: `.dir`. 지금 6칸이에요.
- **디자인 값**: `:root`에 있어요.
  - 바탕: 흰색, `#F5F5F7`(회색), 검정 타일
  - 포인트 색: `#3D33D8`(남색) 하나
  - 글꼴: 시스템 글꼴 → Noto Sans KR
  - 외울 글 예시: Gowun Batang
  - 다크 모드 없이 밝은 화면 하나로 고정
- **휴대폰 전용 스타일**: `@media (max-width:760px)` 묶음에 있어요.

## 새 제품(예: nosces)을 추가할 때 고칠 곳

1. **맨 위 메뉴**: `gnav`에 `<li class="has-fly">`를 하나 더 넣어요. `#msheet`에도 링크를 넣어요.
2. **제품 화면**: `v-blinder`를 복사해서 `<div class="view" id="v-새이름" hidden>`을 만들고, 위 순서대로 내용을 채워요. 구역 `id`는 `새이름-find`처럼 `새이름-` 뒤에 붙여요.
3. **스크립트**
   - `NOTES`와 `CRUMB`에 새 화면을 추가해요.
   - 로고가 필요하면 `LOGO_N`과 `.logo-n` 바꾸기 코드를 추가해요.
4. **홈**
   - 큰 타일(`.tile.full.htile`)이나 넘겨 보는 타일을 추가해요.
   - 비교표 `.pick`을 3칸으로 바꿔요.
     - `.pick`의 `grid-template-columns`를 3칸으로 바꿔요.
     - `.pbar`(휴대폰에서 위에 붙는 이름 줄)에도 이름을 하나 더 넣어요.
     - 줄마다(`.rl` 아래) `.v`를 하나씩 더 넣어요.
5. **바닥글 `.dir`**: 제품 칸과 약관 칸을 추가하고, 칸 수를 고쳐요.
6. **고객지원과 회사 소개**: 자주 묻는 질문, 약관 링크(`.legals`), 회사 소개의 "만드는 것" 목록에 추가해요.

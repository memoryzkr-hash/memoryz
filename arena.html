사용법

      
Claude Code에서 부르기

    

    
    
      
  1. 이 저장소를 Claude Code로 열고 과제와 함께 부릅니다
    
        
    "이거 대결 붙여줘"라고 해도 됩니다. Claude가 과제를 task.md로 정리하고, 호출 수를 알려 준 뒤 시작합니다.
    
        
    /arena --quick 회원가입 폼 검증 로직을 짜줘
    2. 
      
  2. 다른 프로젝트에서도 쓰려면 스킬 폴더를 복사합니다
    
        
    Python 3.8 이상만 있으면 됩니다. 표준 라이브러리만 씁니다.
    
        
    cp -r .claude/skills/arena ~/.claude/skills/
    3. 
      
  3. 결과는 실행 폴더에 남습니다
    
        
    final.md에 최종 답이, result.md에 경기별 점수와 판정 이유, 대진표가 있습니다. 중간에 끊겨도 같은 폴더에서 이어 갈 수 있습니다.
    
        
    python3 .claude/skills/arena/scripts/arena.py status latest
    4. 
    

    
    
      
  • 같은 모델이 서로 다른 지시로 푸는 방식입니다. 서로 다른 AI 여럿이 겨루는 것은 아닙니다.
    • 
      
  • 가장 좋은 답을 보장하지는 않습니다. 과제가 모호하면 결과도 흐려집니다.
    • 
      
  • 토큰은 쓰는 사람의 Claude 사용량에서 나갑니다. 평소에는 --quick(8명, 43회)이면 충분합니다.
